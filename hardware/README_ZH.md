# 硬件公开集成边界

这个目录只记录 QnEvt 熵节点面向主机的公开硬件契约。

## 已公开

- 面向主机的串口协议。
- 默认公开链路假设：
  - UART 波特率：`2000000`
  - UART TX：`GP0`
  - UART RX：`GP1`
  - USB CDC 字节流也可以暴露同样的帧格式数据包。
- 高层节点行为：
  - 输出调理后的熵块
  - 输出遥测快照
  - 输出告警和停止输出的错误
  - 接受重启和 BOOTSEL 控制命令

## 不公开

- 公开最小基线之外的生产固件内部实现
- 传感器采样实现
- 熵调理实现
- 私有健康测试阈值
- 私有校准值
- 板卡原理图、PCB layout、CAD 文件、BOM、供应商说明或制造文件
- 设备序列号、node token、push key、服务端 URL 或部署配置

## 集成方式

主机软件应通过 [../docs/firmware_protocol_ZH.md](../docs/firmware_protocol_ZH.md) 集成，而不是依赖私有固件或板卡内部实现。
